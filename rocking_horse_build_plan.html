Physical Setup

Inside the enclosure (permanent)

  • Raspberry Pi 3 A+
  • Grove Base HAT plugged onto the Pi’s 40-pin header
  • LIS3DHTR Accelerometer stuck flat to the inside bottom with foam tape
  • Waveshare LCD mounted through a hole in the enclosure wall, facing out
  • Powerbank sitting alongside the Pi

Connected from outside (unplug for transport)

  • Button cable through the enclosure wall
  • Speaker via 3.5mm jack
  • Powerbank via micro-USB (to the Pi’s PWR port)

Keep the accelerometer still for the first second after power-on — the script calibrates its resting position automatically.

Wiring

Accelerometer → HAT

Plug the Grove cable into any of the three I2C slots on the HAT. The other end plugs into the accelerometer.

HAT (any I2C slot) ---- Grove cable ---- LIS3DHTR accelerometer

Button → HAT

IMPORTANT — only connect Yellow and Black wires.
The Grove conversion cable has four wires: Yellow (signal/GPIO5), Black (GND), Red (3.3V), White (secondary signal).
Tape off Red and White before connecting anything. If Red touches Black even momentarily it will short-circuit the Pi. 
HAT D5 slot | Grove plug [Yellow + Black only] -> Dupont housing -> button cable -> spades -> button

The | marks where you disconnect the conversion cable ends from the Dupont housing for transport.

LCD Screen → HAT pass-through pins

The display’s 8 female Dupont wires push directly onto the GPIO header pins exposed on top of the HAT.

Both Pin 1 (VCC) and Pin 17 (BL) are 3.3V — they go to two separate pins, no wires need joining.

Attachment & Detachment

To attach: insert the conversion cable into the D5 plug, connect the Dupont housing ends to the button cable, and plug in the speaker and power.

To detach for transport: remove the conversion cable ends from the Dupont housing, unplug the speaker and power.

For detailed instructions, see README.md.

Software Setup Overview

For complete step-by-step software installation instructions, see README.md.

The installer script (install.sh) performs these tasks automatically:

  • Enable I2C & SPI — adds kernel modules and modifies /boot/config.txt for the accelerometer and display
  • Install packages — system tools (i2c-tools, alsa-utils) and Python libraries (pillow, smbus2, gpiozero, numpy)
  • Configure audio — writes ~/.asoundrc to route sound to the 3.5mm jack (needed for Raspberry Pi OS Bookworm with PipeWire)
  • Install Waveshare LCD driver — downloads and patches the display library
  • Install rocking_horse.py — the main control script
  • Register systemd service — enables autostart on boot
  • Set permissions — adds the pi user to gpio, spi, i2c, audio groups

Write Protection (Final Safety Step)

After all testing is complete, enable the read-only overlay filesystem as a safety measure. This prevents SD card corruption if power is lost unexpectedly.

SSH into the Pi and run:

sudo raspi-config

Navigate to Performance Options → Overlay FS and select Yes. When asked about write-protecting the boot partition, select No. Reboot.

Important: Once write protection is enabled, all filesystem changes are lost after reboot. If you need to make permanent changes, disable write protection first in raspi-config, make your changes, then re-enable it. This is by design — the overlay filesystem protects against unexpected power loss.
